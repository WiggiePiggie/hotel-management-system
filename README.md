# Hotel Management & Reservation System

Private repository reserved for the sanitized Python/SQLite hotel management portfolio project.

**Import status:** The application source and automated tests have **not yet been uploaded** to this GitHub repository. The sanitized project exists in a separate local Git package prepared for upload. Do not treat this repository as runnable until `database.py`, `main.py`, `pages/`, `ui/`, and `tests/` have been pushed.

## Import locally

1. Download and extract the prepared `Hotel_Management_Local_Git_Repository.zip` package from the ChatGPT conversation.
2. Ensure Git for Windows is installed.
3. Open PowerShell in the extracted directory containing `main.py` and `.git`.
4. Run:

```powershell
git remote add origin https://github.com/WiggiePiggie/hotel-management-system.git
git push -u origin main --force-with-lease
```

**Safety:** The sanitized package excludes original guest/customer databases, backups, and executable builds. The repository is intentionally private until rights to publish code developed for the business are confirmed.

The packaged project previously passed 14 Python unit/integration tests. Desktop GUI flows have not been comprehensively validated.
